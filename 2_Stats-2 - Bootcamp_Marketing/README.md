## Project Overview
This project aims to evaluate the effectiveness of advertising campaigns across various digital channels (Instagram, Google, Facebook, and TikTok) during 2024. The analysis focuses on the relationship between budget allocation (AdBudget), audience type, and revenue generated. This datased used data dummy.


## Variables Description

- CampaignID : Campaign Identity
- Channel : The platform where the ads run.
- AudienceType : Type of targeting audience
- AdBudgetK : The advertising budget spent.
- CTR : Click Through Rate
- ConversionRate : Conversion Rate
- Month : Month
- RevenueK : The income generated by generated
